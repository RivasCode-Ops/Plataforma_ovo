# Alertas e notificações

## No painel

Menu **Alertas** — lista unificada:

| Tipo | Quando aparece |
|------|----------------|
| Pedido novo | Status `novo` (ainda não confirmado) |
| Estoque baixo | Menos de 10 unidades |
| Sem estoque | Zero unidades (urgente) |
| Lote vencendo | Validade em até 7 dias |
| Lote vencido | Validade passada (urgente) |
| Assinatura hoje | Entrega programada para hoje |
| Assinatura atrasada | Data de entrega já passou (urgente) |

Clique no alerta para ir à seção correspondente.

A lista **atualiza sozinha** a cada 1 minuto.

## Push no celular (PWA)

1. Instale o app no celular ([PWA.md](PWA.md))
2. **Alertas** → **Ativar no celular**
3. Aceite a permissão do navegador

Quando surgir um alerta **urgente** novo, o celular mostra notificação (com o painel fechado, se o SO permitir).

## E-mail

Não implementado na Fase 2 — apenas alertas no painel e push local do navegador.
